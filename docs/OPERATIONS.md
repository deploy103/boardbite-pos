# OPERATIONS.md

> 부스 운영 직원(개발자가 아닌 학생 포함)을 위한 실전 운영 매뉴얼.
> 구현 완료 후 실제 화면 기준으로 작성한다. 현재는 스켈레톤 상태.

## 목차 (작성 예정)

- 서버 시작/종료
- 직원 로그인
- 자리 배정 및 테이블 OPEN
- NFC/QR 문제 대응
- 주문 누락 대응
- 주방 화면 사용법
- 서빙 처리
- 현금 정산 / 더치페이 / 상품별 결제
- 잘못 결제했을 때 취소 방법
- 테이블 강제 CLOSE
- 품절 처리
- 네트워크 장애 대응
- 백업
- 마감 절차
- 다음날 초기화
